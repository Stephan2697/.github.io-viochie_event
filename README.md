# Viochie Events - Wilfred Ochia's Portfolio Project

## 🎯 Project Overview

A complete, production-ready event planning website featuring:
- **Frontend:** Responsive HTML5/CSS3/JavaScript website
- **Backend:** Node.js/Express.js REST API with email notifications
- **Features:** Contact form with validation, email confirmations, and comprehensive documentation

**Status:** ✅ Complete & Deployment-Ready (January 20, 2026)

## 🚀 Quick Start (2 Minutes)

```bash
# 1. Enter backend folder
cd github.io-viochie_event-main/backend

# 2. Install dependencies
npm install

# 3. Setup environment
cp .env.example .env
# Edit .env with your email credentials

# 4. Start server
npm start

# 5. Open frontend in browser
open ../.github.io-viochie_event-main/index.html
```
